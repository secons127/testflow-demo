# TestFlow Prototype

QA 업무에서 자주 사용하는 용어와 음성통화 검증 절차를 쉽고 재미있게 학습할 수 있도록 제작한 웹 기반 학습 프로토타입입니다.

용어 학습, 절차 순서 퀴즈, Mock AI 질문 등의 기능을 통해 단순히 내용을 읽는 방식에서 벗어나 사용자가 직접 참여하며 업무 지식을 익힐 수 있도록 구성했습니다.

---

## 프로젝트 제작 배경

처음 QA 업무를 시작했을 때 현장에서 사용하는 용어들이 생소하고 어렵게 느껴졌습니다.

용어의 뜻을 검색하더라도 실제 업무에서 어떤 상황에 사용되는지 바로 이해하기 어려웠고, 음성통화 검증 절차 역시 여러 단계로 구성되어 있어 처음에는 전체 흐름을 익히는 데 어려움이 있었습니다.

이러한 경험을 바탕으로, 처음 업무를 접하는 사람도 용어와 테스트 절차를 단계적으로 학습할 수 있는 서비스를 만들어 보고자 했습니다.

단순히 용어 설명을 모아 두는 것에서 그치지 않고, 학습 완료 기록, XP, 절차 블록 퀴즈와 같은 요소를 추가하여 사용자가 직접 참여하면서 반복적으로 학습할 수 있도록 제작했습니다.

또한 기존에 익숙하게 사용하던 JavaScript에서 한 단계 더 나아가 **TypeScript를 직접 사용해 보고 싶어 시작한 프로젝트**입니다.

개발 과정에서는 생성형 AI와 대화하며 아이디어를 구체화하고 코드를 작성·수정하는 **바이브 코딩 방식**을 활용했습니다.

AI가 생성한 코드를 그대로 사용하는 것에 그치지 않고, 각 기능이 어떤 구조로 동작하는지 확인한 뒤 필요한 부분을 직접 수정하고 테스트하며 프로젝트를 완성했습니다.

---

## 주요 기능

### 1. 용어 학습

QA 업무에서 자주 사용되는 주요 용어의 의미와 설명을 학습할 수 있습니다.

각 용어를 단순히 나열하는 것이 아니라, 처음 업무를 접하는 사용자도 이해할 수 있도록 비교적 쉬운 설명으로 구성했습니다.

### 2. 학습 완료 및 XP 저장

사용자가 학습을 완료한 항목과 획득한 XP를 기록합니다.

학습을 완료할수록 XP가 누적되어 사용자가 자신의 학습 진행 상황을 확인할 수 있습니다.

### 3. 음성통화 절차 블록 순서 퀴즈

음성통화 검증 절차를 여러 개의 블록으로 나누어 제공합니다.

사용자는 제시된 블록을 올바른 순서로 직접 배열하며 테스트 절차의 전체 흐름을 학습할 수 있습니다.

하나의 정답을 단순히 선택하는 방식이 아니라, 테스트 케이스의 순서를 직접 구성하도록 하여 절차에 대한 이해도를 높이고자 했습니다.

### 4. Mock AI 질문

용어나 테스트 절차에 관한 질문을 입력하면 AI 형태의 답변을 확인할 수 있습니다.

현재는 실제 OpenAI API와 연결하지 않고, 미리 구성된 Mock 응답을 반환하는 프로토타입 기능입니다.

### 5. 마이페이지

사용자의 학습 진행 상황을 확인할 수 있습니다.

마이페이지에서는 다음 정보를 확인할 수 있습니다.

* 완료한 학습 항목
* 획득한 XP
* 전체 학습 진행률
* 퀴즈 및 활동 기록

### 6. 브라우저 기록 저장

별도의 서버나 데이터베이스 없이 브라우저의 `localStorage`를 이용하여 사용자의 기록을 저장합니다.

저장되는 정보는 다음과 같습니다.

* 학습 완료 기록
* 획득한 XP
* 퀴즈 진행 기록
* AI 질문 대화 내용

브라우저 데이터를 삭제하거나 다른 브라우저 또는 기기에서 접속하면 기존 기록이 유지되지 않을 수 있습니다.

## 로컬 실행

프로젝트를 실행하기 전에 Node.js와 npm이 설치되어 있어야 합니다.

```bash
npm install
npm run dev
```

명령어를 실행한 후 터미널에 표시되는 로컬 주소로 접속합니다.

---

## 빌드 확인

```bash
npm run build
npm run preview
```

`npm run build` 명령어를 통해 프로젝트가 정상적으로 빌드되는지 확인할 수 있습니다.

`npm run preview` 명령어를 실행하면 빌드된 결과물을 로컬 환경에서 미리 확인할 수 있습니다.

## 프로젝트 특징

* 실제 QA 업무 경험에서 출발한 학습 서비스
* 어려운 용어를 쉽게 이해하기 위한 학습 콘텐츠
* QA 업무와 게임형 학습 요소의 결합
* 테스트 절차를 직접 배열하는 참여형 블록 퀴즈
* 학습 완료 및 XP를 활용한 진행 상황 관리
* TypeScript를 활용한 웹 프로젝트 제작 경험
* 생성형 AI를 활용한 바이브 코딩 방식 적용
* 별도의 백엔드 없이 실행 가능한 정적 웹 애플리케이션
* `localStorage`를 활용한 사용자 기록 유지

## 개발 과정

프로젝트의 전체적인 화면 구성과 기능 아이디어를 먼저 정리한 뒤, 생성형 AI와 대화하며 각 기능에 필요한 코드를 구현했습니다.

개발 과정에서 다음과 같은 작업을 진행했습니다.

1. 용어 학습 화면 구성
2. 학습 완료 상태 및 XP 저장 기능 구현
3. 음성통화 절차 블록 퀴즈 구현
4. 다양한 테스트 케이스를 선택할 수 있도록 퀴즈 구조 개선
5. 사용자가 직접 블록 순서를 조합할 수 있도록 기능 수정
6. Mock AI 질문 및 응답 화면 구현
7. 마이페이지와 학습 진행률 표시
8. `localStorage`를 활용한 데이터 저장
9. TypeScript 타입 오류 및 빌드 오류 수정
10. 화면과 기능을 반복적으로 테스트하며 UI 개선

바이브 코딩 방식으로 빠르게 프로토타입을 구현했지만, 생성된 코드가 실제로 어떻게 동작하는지 확인하며 컴포넌트 구조, 상태 관리, 데이터 저장 방식 등을 직접 수정했습니다.

## 제한 사항

현재 프로젝트는 기능 검증과 학습을 목적으로 제작된 프로토타입입니다.

* AI 질문 기능은 실제 OpenAI API를 사용하지 않습니다.
* 회원가입 및 로그인 기능이 없습니다.
* 사용자 데이터가 서버에 저장되지 않습니다.
* 브라우저 데이터를 삭제하면 학습 기록이 초기화될 수 있습니다.
* 다른 브라우저나 기기 간에 기록이 동기화되지 않습니다.
* 일부 학습 콘텐츠와 테스트 케이스는 예시 데이터로 구성되어 있습니다.
